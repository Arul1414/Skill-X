# 📖 About

**SkillX** is an AI-powered peer-to-peer learning platform that enables users to **teach skills, learn from others, collaborate with peers, and prepare for interviews using AI-powered assistance.**

The platform combines modern web technologies with Artificial Intelligence to create an engaging learning experience featuring skill exchange, AI interview coaching, resume analysis, and real-time collaboration.
